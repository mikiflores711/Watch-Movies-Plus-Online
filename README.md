# CinePlay con generador TMDB

## Publicar
Sube todo el contenido de esta carpeta a la raíz de tu repositorio de GitHub Pages.

## Agregar una película o serie
1. Abre `generador.html` desde el sitio publicado o mediante un servidor local.
2. Introduce tu **API Read Access Token** de TMDB.
3. Busca por ID o título.
4. Selecciona el resultado, agrega el MP4/M3U8 y genera el ZIP.
5. Copia el HTML generado a la raíz y reemplaza `data/catalogo.js`.

El diseño visual del archivo original no fue modificado; solo se separaron los recursos y se cambió la navegación para usar páginas individuales.
